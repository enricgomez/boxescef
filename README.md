# boxescef

Boxes Alojamientos Camping El Far: plugin de WordPress **Custom Call to action Elementor Addon** (carpeta `c_c_t_a`), que añade a Elementor el widget «Custom Call To Action» (imagen, título, descripción e icono con enlace). Se usa en las tarjetas de alojamientos de campingelfar.com.

## Instalar o actualizar

Descarga `dist/c_c_t_a-<versión>.zip` y súbelo en Plugins > Añadir nuevo > Subir plugin, eligiendo «Reemplazar la versión actual».

No uses el zip «Source code» de GitHub: crea la carpeta `boxescef-main` en lugar de `c_c_t_a`, y WordPress lo instalaría como un plugin distinto.

El historial de cambios está en `README.txt`.
